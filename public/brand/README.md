# Official Brand Logo Directory

Drop your official TrueReview logo assets in this folder:
- `public/brand/logo.svg` (Recommended vector logo)
- OR `public/brand/logo.png` (High-res transparent PNG)
- `public/brand/favicon.ico`

The `<Logo />` component in `src/components/ui/logo.tsx` will automatically detect and render your official asset with zero configuration required. If no asset is present, it uses the clean typographic fallback.
